# [TYPE] 대상 + 목표

## 배경

이 작업이 필요한 맥락을 설명한다.
기존 코드, 사용자 흐름, Analytics 의미, 후속 Issue와의 관계처럼 작업 판단에 필요한 정보를 남긴다.

## 문제 또는 정리 대상

현재 코드나 동작의 문제, 또는 문서/리팩토링/실험 작업에서 정리하려는 대상을 구체적으로 적는다.

- 어떤 파일, 메서드, 화면에서 문제가 발생하는지
- 현재 동작이 왜 잘못되었거나 위험한지
- 사용자가 보게 되는 문제, 데이터상 문제, 또는 정리하려는 판단 기준이 무엇인지

## 목표

이번 Issue에서 달성할 상태를 적는다.

- 변경 후 기대 동작
- 책임 분리 기준
- 성공/실패 판단 기준

## 작업 내용

- [ ] 수정할 파일 또는 흐름
- [ ] 추가할 테스트
- [ ] 필요한 문서 갱신
- [ ] Analytics 이벤트 변경 시 상수와 문서 동시 갱신

## 완료 조건

- [ ] 정상 동작 확인
- [ ] 관련 분석 또는 빌드 명령 통과
- [ ] 필요한 테스트 통과
- [ ] Analytics 변경 시 DebugView 확인 또는 PR 테스트 항목에 명시
- [ ] 코드와 문서의 이벤트 정의 일치

## 메모

이번 Issue에서 제외하는 범위, 후속 Issue, 판단 보류 사항을 적는다.
